# Личная экосистема в Telegram

Модульный Telegram-бот (Python, aiogram 3, SQLite). Каждый раздел — отдельный модуль
в `bot/modules/`, главное меню собирается из списка модулей автоматически.

| Модуль | Статус |
|---|---|
| 📁 **Досар** — отслеживание досара на гражданство Румынии по ст. 11 | готов |
| 💼 **Портфель** — инвестиции | заготовка |

## Модуль «Досар»

- несколько досаров на пользователя (номер вида `12345/RD/2021`), с названиями («Мама», «Я»);
- фоновая проверка сайта ANC (cetatenie.just.ro) каждые `CHECK_INTERVAL_MIN` минут:
  бот собирает ссылки на PDF со страниц `ANC_SOURCE_PAGES` (Stadiu dosar и Ordine),
  скачивает их и индексирует все номера досаров;
- **уведомления**: номер появился в приказе 🎉, изменилась строка о нём в Stadiu dosar 🔔,
  ANC опубликовал новые приказы 📰 (отключается);
- карточка досара: текущий статус, строки из документов со ссылками на PDF, история,
  дата подачи и сколько дней ждём;
- статистика по году подачи: сколько досаров этого года уже в приказах, максимальный номер,
  сколько с номером меньше вашего (ориентир, не прогноз);
- `/check 12345/RD/2021` — проверить любой номер без добавления;
- админ: `/admin`, `/refresh`, `/broadcast`, оповещение, если сайт ANC перестал отвечать.

**Как парсятся PDF.** Парсер не завязан на колонки таблиц: ищет в тексте номера `N/RD/YYYY`
и сохраняет строку, где номер встретился. Уже опубликованные приказы повторно не скачиваются;
списки Stadiu dosar перекачиваются и сравниваются по хешу. При самом первом запуске
загружается весь архив без рассылки уведомлений.

> ⚠️ Сайт ANC может не отвечать с зарубежных/облачных IP. Если в `/admin` видно, что
> проверки не проходят, укажите `ANC_PROXY` (например, румынский HTTP-прокси).

## Запуск

```bash
cp .env.example .env      # вписать BOT_TOKEN и свой ADMIN_IDS
docker compose up -d --build
```

Без Docker:

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python -m bot
```

## Разработка

```bash
pip install -r requirements-dev.txt
pytest
```

Новый модуль: пакет `bot/modules/<name>/` с функцией `setup(ctx) -> Module`
(см. `bot/modules/portfolio`), затем добавить его в `MODULES` в `bot/__main__.py`.
