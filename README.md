# Отчёт Booking + Airbnb для бухгалтера (SAGA, Румыния)

Программа раз в месяц собирает все бронирования из Booking.com и Airbnb и делает:

1. **Excel-отчёт для бухгалтера** `Raport_cazare_ГГГГ-ММ.xlsx` (на румынском):
   итоговая сводка + список всех клиентов: имя, страна, даты заезда и выезда, ночи, сумма,
   комиссия платформы, сумма к выплате, **курс BNR на дату** и суммы в RON.
2. **Файл импорта в SAGA** `SAGA_import_ГГГГ-ММ.xml`: документ на каждого клиента
   со сквозной нумерацией (серия `CAZ`). Бухгалтер загружает его через
   *Fișier → Import date → Facturi ieșiri (XML)*.
3. По желанию **отправляет оба файла бухгалтеру на e-mail**.

## Почему нужен один ручной шаг

У Booking и Airbnb нет открытого API для обычных хозяев: доступ дают только крупным
channel-менеджерам. Поэтому раз в месяц нужно скачать **два файла** (около 2 минут)
и положить их в папку `inbox`. Всё остальное программа делает сама.

### Airbnb — файл CSV
Меню → **Доходы** → **Выплаченные (Completed payouts)** → период: прошлый месяц →
**Экспорт CSV**. Получится файл вида `airbnb-completed-from-09.01.26-to-09.30.26.csv`.

### Booking.com — PDF «Отчёт о бронированиях»
Extranet → **Финансы** → **Отчёт о бронированиях** → период: прошлый месяц →
**«Распечатать эту страницу»** → принтер **«Сохранить как PDF»**.
Можно положить и выгрузку CSV/Excel из раздела «Бронирования», если она есть.

Файлы можно назвать как угодно: программа сама определит, где Booking, а где Airbnb.
Повторы между файлами отбрасываются.

**Как гость относится к месяцу** (так же, как в документах площадок):
Airbnb — по дате выплаты (это день после заезда), Booking — по дате выезда.
Если «итого» в PDF Booking не совпадает с суммой строк, программа предупредит.

## Установка (один раз, Windows)

1. Установите Python 3.10 или новее с https://www.python.org/downloads/
   (отметьте галочку **«Add Python to PATH»**).
2. Скачайте эту папку (GitHub → Code → Download ZIP) и распакуйте, например в `C:\Raport`.
3. В этой папке откройте командную строку и выполните:
   ```
   pip install -r requirements.txt
   copy config.example.yaml config.yaml
   ```
4. Откройте `config.yaml` в Блокноте и заполните данные фирмы, серию и первый номер
   документа, ставку НДС и e-mail бухгалтера.

## Использование каждый месяц

1. 1-го числа положить 2 выгрузки в папку `inbox`.
2. Дважды щёлкнуть **`run_report.bat`**: будет сделан отчёт за прошлый месяц.
   - отчёт за конкретный месяц: `run_report.bat --month 2026-10`
   - сразу отправить бухгалтеру: `run_report.bat --send`
3. Готовые файлы лежат в `reports\2026-10\`.
4. В SAGA: импортировать `SAGA_import_….xml` (Fișier → Import date → Facturi ieșiri XML),
   проверить документы и отправить их в **SPV / e-Factura** как обычно.
   Клиенты-физлица получают CNP `0000000000000` (13 нулей), если настоящий неизвестен.

Если какого-то файла не хватает, программа напишет `ATENȚIE` и **не отправит**
письмо, чтобы бухгалтер не получил неполный отчёт.

## Автозапуск в конце месяца

**Windows (Планировщик заданий):**
Создать задачу → Триггер «Ежемесячно», 1-е число, 10:00 → Действие «Запуск программы»:
`C:\Raport\run_report.bat`, аргументы `--send`, рабочая папка `C:\Raport`.

**macOS / Linux (cron):**
```
0 10 1 * * /путь/к/папке/run_report.sh --send
```

Для отправки через Gmail нужен «пароль приложения» (Google-аккаунт → Безопасность →
Пароли приложений). Пароль задаётся в переменной окружения `REPORT_SMTP_PASSWORD`,
а не в файле.

## Настройки, которые нужно согласовать с бухгалтером

| Параметр в `config.yaml` | Что значит | По умолчанию |
|---|---|---|
| `date_basis` | к какому месяцу относить бронь: по выезду, заезду или дате выплаты | `checkout` |
| `bnr_mode` | курс BNR на дату выезда или курс предыдущего банковского дня | `same_day` |
| `vat_rate` | ставка TVA, 0 если вы не плательщик | `0` |
| `saga.mode` | документ на каждого клиента или один сводный на платформу | `per_reservation` |
| `saga.series` / `next_number` | серия и первый номер документов | `CAZ` / `1` |

**Важно:** формат XML для SAGA пусть бухгалтер один раз проверит импортом
(лучше на копии базы). Если он предпочитает другой формат (например, только Excel
или импорт из DBF), это настраивается.

```
pip install -r requirements.txt pytest
python -m pytest tests
```

`bnr.py` (курсы BNR с кэшем), `excel_report.py`, `saga_xml.py`, `mailer.py`,
`__main__.py` (запуск).
